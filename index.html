How I build now

AI writes a lot of code quickly. The value I add is knowing which code should exist, checking that it's right, and getting it through review, the stores and real users. This is the loop I use on every feature.

  1. Frame the problem

    Start from the business process: who taps what, what data moves, what can go wrong. Write it as a short spec before any code.

  2. Pair with AI

    Use an AI coding agent to scaffold screens, state, models and API layers from the spec, then read and reshape every diff.

  3. Test and review

    Generate widget and unit tests alongside the code, run them in CI, and use AI review as a second pass on edge cases.

  4. Ship and measure

    Release through Play Console and App Store Connect, watch crash and policy reports, and feed what I learn into the next spec.
